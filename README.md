# weread-dashboard

一个单文件离线阅读数据看板。页面以 2026-10-21 的静态快照呈现 1939 本出品与轻故事书目的阅读表现，覆盖数据总览、近期上线、趋势分析、多书对比、明细筛选和加推文案六个视图。

页面标题署名为 Annezhou。页面数据已完成脱敏处理，书名、作者、BookID 全部为合成值，各项阅读指标经过确定性变换，无法回推真实读数。仓库中保留的口径文档与脚本用于展示结构设计和方法论，内部表名、平台地址与个人标识均已替换为占位符。

## 直接打开

双击 `index.html` 用现代浏览器打开即可。图表库 ECharts 5.5.0 通过 CDN 加载，首次打开需要联网。页面内的数据、筛选、导出和本地标记都在浏览器内完成，不依赖后端服务。

## 主要功能

- 出品与轻故事两种口径切换
- 新书核心指标 Top 榜、加推判定与勾选持久化
- 数据小结含异常预警，预警书名可点击下钻
- 趋势与多书对比，支持 CSV 导出
- 响应式布局，适配桌面与移动端

## 目录结构

```
index.html                     单文件看板，可直接打开
docs/01_口径与约定.md          加推门槛、榜单位次、分类治理等判定口径
docs/02_每日自动化_提示词原文.md 取数到部署的自动化流程示例（占位符版）
src/                           看板构建与校验脚本（结构展示，不可直接运行）
00_说明.md                     脱敏边界与版本说明
```

## 技术说明

原生 HTML、CSS 与 JavaScript，无构建步骤。图表使用 ECharts 5.5.0。数据以内联 JavaScript 对象写入页面，因此单文件即可离线查看核心内容。

`src/` 中的脚本保留了原始代码结构，用于说明从取数、清洗、重建到部署的设计思路。运行所需的表格 ID、子表 ID、内部平台与个人标识均为占位符，脚本无法直接执行。
